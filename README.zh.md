# dsh-account-balance-pill

[English](README.md) | [中文](README.zh.md)

一个 DeepSeek Harness（DSH）插件：在侧边栏底部账号入口的正上方，用一行显示当前登录账号的**充值余额**和**赠金余额**，每分钟自动刷新，并带一个刷新按钮。

![侧边栏账号入口上方的余额行](docs/preview.svg)

*示意图：充值余额、赠金余额与刷新按钮，位于头像行正上方。*

## 功能

- 两个金额始终同时显示：充值余额与赠金余额，按 Platform 余额卡片的规则格式化（两位小数、千分位、正数小于一分显示 `<¥0.01`）。
- 每 60 秒自动刷新；页面隐藏时暂停；离开超过 10 秒后回到页面或窗口时补刷。
- 右侧刷新按钮点击后立即读取，并重新开始一分钟计时。
- 读取失败时保留上一次成功的金额，显示警示标记，刷新按钮变成警示色，并通过悬停提示和读屏状态说明失败原因。
- 未保存账号凭证时（例如只用 API Key 的配置）隐藏；侧边栏收起为图标栏时也隐藏。
- 只使用 `--dsw-alias-*` 主题令牌，跟随浅色/深色主题。

## 安装

Desktop 使用 `desktop` profile，`dsh web` 使用 `web`；按需替换下面的 `desktop`。

从 GitHub 安装：

```sh
dsh plugin --profile desktop add github:cheny5100/dsh-account-balance-pill
```

从 npm 安装（包发布后可用）：

```sh
dsh plugin --profile desktop add dsh-account-balance-pill
```

从本地目录安装：

```sh
dsh plugin --profile desktop add D:\path\to\dsh-account-balance-pill
```

在**插件**页确认这一行，然后刷新页面。组合包行启用后，浏览器模块由 Host 提供。

## 使用

- 登录 DeepSeek 账号后，侧边栏底部、账号入口正上方会出现与账号行左对齐的余额行。
- 行内显示 `充值 ¥12.34 · 赠金 ¥5.00` 和一个刷新按钮；悬停可看完整金额、最近更新时间和失败原因。
- 点击刷新按钮立即读取；读取期间按钮旋转。
- 侧边栏收起为图标栏时，余额行隐藏。

## 行为

| 情况 | 余额行的表现 |
|---|---|
| 未登录 / 仅 API Key | 隐藏 |
| 首次加载 | 两个金额显示 `—` |
| 成功 | 显示两个金额，每 60 秒刷新 |
| 成功后读取失败 | 保留上次金额，显示警示标记，刷新按钮变警示色，并向读屏软件报告失败 |
| 首次即失败 | 显示本地化的“余额不可用”和刷新按钮 |
| 页面隐藏 | 暂停请求；离开超过 10 秒后回到页面或窗口时补刷 |
| 连续失败 | 退避 60 秒 → 120 秒 → 240 秒 → 300 秒，成功后或手动刷新后恢复 |

没有配置项。

## 兼容性

- DSH `>=0.2.2-rc.3 <0.3.0`，Desktop 与 Web 客户端（`platform: web`）。
- 无运行时依赖、无构建步骤；浏览器包是纯 JavaScript。

## 工作原理

- Host 半是一个空的 `apply()`；它的作用只是让组合包行启用，使 DSH 的客户端模块系统扫描并提供 `./client`。
- 浏览器半注册到 `sidebar.footer.action` 列表插槽，并调用现有的账号 Remote：`ctx.remote.account.getBalance(metadata)`，携带客户端版本、当前语言和 UTC 偏移。
- Host 向配置的 `platformOrigin` 查询当前登录账号的钱包摘要；账号 token 始终留在 Host，浏览器只收到币种和十进制金额字符串。
- 金额在显示前保留服务端精度；格式化规则与 Platform 卡片一致。

## 已知限制

- 只有 DeepSeek 账号登录才有余额；只用 API Key 的配置没有账号入口，也不会显示余额行。
- 收起为 56px 图标栏时不渲染（没有空间放标签）。
- 当前 DSH 没有账号行内部的扩展点，所以余额行位于账号行正上方。
- 当 DSH 自带的动态 Cordis 操作行显示时（仅在有动态 Cordis 插件时出现），两者共用侧边栏底部的同一行，余额行可能被压缩。这是当前侧边栏 footer 布局的限制；没有动态 Cordis 插件时不受影响。

## 开发

修改 `client.js` 即可，没有构建步骤。重新安装组合包或重载插件后刷新页面。
